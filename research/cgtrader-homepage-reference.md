# CGTrader homepage reference

Reviewed 30 October 2026 at https://www.cgtrader.com/ using the publicly returned page structure. No browser screenshot or user usability study was conducted.

Observed: prominent search, category navigation, suggested/trending queries, curated collections, browsing by type/format, and routes for sellers.

Applied to RenderMarket: prominent rounded search beneath the brand introduction; honest suggested searches; category buttons with real catalogue counts; four actual catalogue cards; the existing Everyday Lagos collection; format explanations with a real files link. Brand-first positioning and the credited Sanctuary Temple remain.

Excluded: unsupported scale/sales/trending claims, subscriptions, AI generation services, 3D-print sections without corresponding assets, copied artwork/branding and the owner's banned decorative patterns. The source is a reference, not an instruction to duplicate CGTrader.
