# Interface rules audit

Applied 30 October 2026.

Removed rounded corners, shadows, translucent UI surfaces, purple accents, Inter/Space Grotesk usage, decorative transitions, em dashes and emoji/checkmark glyphs from live interface source. Creator summaries now use a list; related products use two columns. Static original brand geometry and functional controls remain. No Lucide dependency, feature-card trio, pricing-tier trio, terminal mockup, gradient/orb decoration, bento layout or dot-grid decoration was introduced.

Added static image skeletons with load/error completion states, linked Terms of Use and Privacy Policy, and retained real GLB inspection. Historical raster comparisons were retired from the website. Original 3D renders are artwork, not decorative UI effects.

JavaScript syntax, catalogue logic and local link checks were performed. Physical iPhone and full browser interaction testing remain pending.
