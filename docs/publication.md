# Publication checklist

## GitHub

Create a **public** repository named `rendermarket-ui-ux` in the intended owner's account and push this project directory as its root. Suggested description: “Self-initiated, AI-assisted UI/UX portfolio concept for an African digital asset marketplace. Design system, original procedural studies and simulated prototype.”

Review the README, licence notices and assistance disclosure. Keep private personal files and the original Downloads documents out of the repository. The project contains only prepared project sources and original generated assets.

For a public browser preview, GitHub Pages can serve the repository's static files. After Pages is configured, the prototype lives at the actual deployed repository URL with `/prototype/` appended. Do not publish a guessed URL in the README. Test the deployed path, image paths and both journeys before adding it to an application.

## Figma

Import and inspect the prepared design using [the Figma handoff](figma-handoff.md). Set the intended viewing audience, copy the actual prototype URL and test signed-out access. Add only the verified URL to the README.

## Application description, after owner review

“RenderMarket is a self-initiated UI/UX portfolio project I began in October 2026. It explores an asset marketplace centred on African digital creatives and culturally specific objects, materials and environments. It includes a design system and simulated buyer/creator journeys. I used AI assistance during development; the portfolio documentation describes the scope and limitations. This is separate from my Access Forge competition proposal.”

Use only wording that accurately reflects the owner's real review, refinements and work. Do not claim a published Figma prototype until it exists.
