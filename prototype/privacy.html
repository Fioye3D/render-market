Privacy Policy

Updated 30 October 2026. This page describes the current RenderMarket portfolio prototype.

Prototype inputs

Search terms, selected filters, saves and demonstration form fields are kept in the current page session. The application does not submit these fields to an account, payment or upload backend. Avoid entering personal or sensitive information into demonstration forms.

Hosting requests

The public site is hosted by GitHub Pages. Loading pages, images and downloads sends normal technical request information, including your IP address, to the hosting provider. GitHub handles that information under its Privacy Statement.

Tracking and external links

The authored prototype does not include analytics, advertising trackers or application cookies. External GitHub and Instagram links are governed by those services' policies. The current interface uses system fonts and local viewer files.

Public contributions and questions

Comments or issues you post on the public repository may be visible to others. Contact the creator through the project owner's GitHub profile for privacy questions, without posting sensitive details publicly.
